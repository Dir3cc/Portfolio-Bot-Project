Project Manager Bot

A simple Discord bot to save your projects.

Commands:

`!start` - start the bot
`!info` - show all commands
`!new_project` - add a new project
`!projects` - see your projects
`!update_projects` - change a project
`!skills` - add a skill to a project
`!delete` - delete a project

How to use:

1. Install the library:
pip install discord.py
2. Create a `config.py` file:
TOKEN = "YOUR_BOT_TOKEN"
DATABASE = "database.db"
3. Run the bot:
python bot.py
